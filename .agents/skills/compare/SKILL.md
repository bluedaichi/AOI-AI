# 比較検討

保存先：比較する対象に関係するフォルダ（例：20_Areas/移住検討/YYYY-MM-DD-比較.md）

## 手順
1. 選択肢と「いつまでに何を決めるか」を確認する。
2. 30_Resources/me/プロフィール.md の「優先順位」から評価軸を作り、ユーザーに確認する（軸は5つまで）。
3. 各選択肢の事実を集める。足りない事実は research スキルで調べるか、「要確認」として残す。
4. 表にする：行＝選択肢、列＝評価軸（数字は単位付き）。各セルに根拠を短く書く。
5. 結論を書く：
   - おすすめ1つと、その理由（優先順位のどれに効くか）
   - 選ばなかった案を選ぶべき条件（「〜なら B」）
   - 決める前に確かめること（最大3つ）
6. 重要な判断（お金・住まい・仕事）は、CLAUDE.md の手順で Codex にレビューさせてから提示する。

## 注意
- 本人の優先順位と違う価値観で勧めない。
- 分からない数字を推測で埋めない。
