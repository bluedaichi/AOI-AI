# 引き継ぎメモの更新

## 手順
1. _agent/progress.md を読む。
2. このセッションでやったことを確認する（変更したファイル、決まったこと）。
3. progress.md を次の形に更新する。古い「完了」は最新5件だけ残し、それより前は削除する。

```
# progress

最終更新：YYYY-MM-DD HH:MM（Claude Code / Codex）

## 進行中
- [ ] タスク名 — 現状 / 次にやること / 関係ファイル [[...]]

## 待ち（人の判断・返事待ち）
- タスク名 — 誰の何を待っているか

## 決まったこと
- YYYY-MM-DD 決定内容（理由を一言）

## 完了（最新5件）
- YYYY-MM-DD タスク名
```

## 注意
- 推測で書かない。未確定のことは「待ち」に入れる。
- 1項目は1行に収める。詳細は該当ノートへのリンクで示す。
