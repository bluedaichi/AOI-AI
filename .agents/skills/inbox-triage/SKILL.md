# Inbox 整理

## 手順
1. 00_Inbox/ のファイルを一覧にする。
2. 1件ずつ内容を読み、移動先を決める。
   - 期限のある取り組みに関するもの → 10_Projects/<プロジェクト名>/
   - 継続的な担当に関するもの → 20_Areas/<領域名>/
   - 参考資料・手順 → 30_Resources/
   - その日の出来事・作業記録 → 40_Daily/ の該当日に追記
   - 判断できないもの → 00_Inbox/ に残し、一覧に「要確認」と書く
3. 移動前に「ファイル名 → 移動先 / 理由（10字程度）」の一覧をユーザーに見せ、了承を得る。
4. 了承後に移動する。各ノートの先頭に frontmatter がなければ付ける：
   ```
   ---
   created: YYYY-MM-DD
   tags: []
   ---
   ```
5. 関連する既存ノートがあれば、本文末尾に「関連：[[ノート名]]」を追記する。
6. 最後に vault-lint を実行し、新しいリンク切れがないことを確認する。

## 注意
- 内容の書き換えはしない（整形と frontmatter 追加のみ）。
- 新しいプロジェクトフォルダを作るときは、ユーザーに名前を確認する。
