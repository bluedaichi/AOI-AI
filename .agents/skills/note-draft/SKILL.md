# note 記事の下書き

保存先：10_Projects/note-shueki/drafts/YYYY-MM-DD-slug.md

## 手順
1. 企画を固める（ユーザーに確認してから次へ）
   - 誰に向けた記事か（読者を1人に絞る）
   - 読者が読み終えて得るもの（1文）
   - 無料か有料か。有料なら、無料部分で何を約束し、有料部分で何を渡すか
   - 材料：ユーザーの実体験・メモ（00_Inbox や 40_Daily から関連するものを探して提示する）
2. 構成案を作る：タイトル案3つ、見出し4〜7個、各見出しで言うことを1行ずつ。ユーザーの了承を得る。
3. 本文を書く
   - 冒頭3行で「誰の・どんな悩みに・何を渡すか」を示す
   - 実体験・具体的な数字・失敗談を優先し、一般論だけの段落を作らない
   - 30_Resources/me/文体ガイド.md があれば従う
4. frontmatter を付ける：
   ```
   ---
   created: YYYY-MM-DD
   tags: [note, draft]
   status: draft
   price: free | paid
   ---
   ```
5. CLAUDE.md の手順で Codex にレビューを依頼し（観点：読者に約束したものを渡せているか、事実の正確さ、有料部分の価値）、指摘を反映する。
6. 完成したら status を ready にし、_agent/progress.md に1行追加する。

## 注意
- 他人の記事・書籍の文章を写さない。引用は出典を明記し短くする。
- 実績や収益の数字を盛らない。ユーザーが言っていない成果を書かない。
- 勤務先や職場の人が特定できる内容を書かない。
