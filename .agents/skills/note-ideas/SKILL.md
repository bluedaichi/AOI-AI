# note のネタ出しと実績管理

ファイル：
- ネタ帳：10_Projects/note-shueki/ネタ帳.md
- 実績表：10_Projects/note-shueki/実績.md

## A. ネタ出し
1. 40_Daily/ と 00_Inbox/ の直近2週間を読む。
2. 30_Resources/me/プロフィール.md の「得意・好き」「実績」と重なる体験を優先して、ネタを5つ出す。各ネタは：
   - タイトル案 / 想定読者 / 読者が得るもの（1文） / 材料になったメモ [[リンク]] / 無料か有料か
3. ネタ帳.md に追記し、ユーザーが選んだものは note-draft スキルへ渡す。

## B. 実績の記録
1. ユーザーから数字（PV、スキ、売上、フォロワー増）を聞き、実績.md の表に1行追加する：
   | 公開日 | タイトル | 無料/有料 | PV | スキ | 売上 | メモ |
2. 数字はユーザーが言ったものだけを書く。

## C. 次の打ち手
1. 実績.md 全体を見て、伸びた記事と伸びなかった記事の違いを3つ以内で指摘する。
2. 目標（プロフィールに記載）との差を数字で示し、次の2週間でやることを最大3つ提案する。
3. 根拠が少ない（記事5本未満）ときは、そう明記して仮説として出す。
