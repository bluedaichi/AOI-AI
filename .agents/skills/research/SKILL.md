# 調べもの

保存先：30_Resources/research/YYYY-MM-DD-テーマ.md

## 手順
1. 何を決めるための調査かを1文で確認する（不明ならユーザーに聞く）。
2. 検索は短いキーワードで複数回。公式サイト・一次情報を優先し、まとめサイトは補助に留める。
3. 数字・日付・価格は、実際に開いたページから取る。検索結果の要約だけで書かない。
4. 次の形で書く：
   ```
   ---
   created: YYYY-MM-DD
   tags: [research]
   ---
   # テーマ
   結論：（何を決めるための調査で、答えは何か。1〜2文）
   ## 分かったこと
   - 事実（[出典名](URL)、確認日）
   ## 分からなかったこと・要確認
   ## 自分の場合の当てはめ（30_Resources/me/ に照らして）
   ```
5. 関連ノートに [[リンク]] を張る。

## 注意
- 他サイトの文章を長く写さない。要点を自分の言葉でまとめる。
- 古い情報（1年以上前）は日付を明記する。
