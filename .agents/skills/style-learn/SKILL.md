# 文体の学習

## 手順
1. 材料を集める：ユーザーが指定した文章、または 10_Projects/note-shueki/ の公開済み記事（status: published）や、ユーザーが手直しした下書き。AI が書いたままの文章は材料にしない。
2. 次の観点で特徴を抜き出す（各項目、実例の短い引用を1つ添える）：
   - 一人称、語尾、文の長さ、段落の長さ
   - よく使う言い回し、使わない言い回し
   - 構成の癖（冒頭の入り方、締め方、見出しの付け方）
   - 温度感（体験談の多さ、断定の強さ、ユーモア）
3. ユーザーが下書きを直した場合は、AI の元の文と直した後の文を比べ、「AI がやりがちで、本人が嫌がったこと」を「使わない言い回し」に追記する。
4. 30_Resources/me/文体ガイド.md を更新する。既存の記述は消さず、矛盾するものだけ新しい方に置き換える。
5. 変更点を3行以内でユーザーに伝える。
