# Vault 点検

## 点検項目
1. リンク切れ：本文中の [[ノート名]]（| や # 以降は除く）に対応する .md ファイルが Vault 内に存在するか。
2. frontmatter：00_Inbox/ と _agent/ 以外の .md ファイルが `---` で始まり、created を持っているか。
3. Inbox：00_Inbox/ の件数（10件以上なら inbox-triage を提案する）。
4. 引き継ぎ：_agent/progress.md の最終更新が7日以上前なら知らせる。

## 進め方
- 点検は読み取りのみで行い、ファイルは修正しない。
- 可能ならスクリプト（grep など）でまとめて調べ、結果だけを読む。
- 結果を次の形でユーザーに報告する：
  ```
  リンク切れ：n件（ノート名 → 存在しないリンク先）
  frontmatterなし：n件
  Inbox：n件
  ```
- 修正はユーザーの了承を得てから行う。
