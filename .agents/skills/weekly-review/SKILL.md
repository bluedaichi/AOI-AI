# 週次レビュー

保存先：40_Daily/YYYY-Www-review.md（例：2026-W41-review.md）

## 手順
1. 材料を集める（読むだけ）
   - 40_Daily/ の直近7日分
   - _agent/progress.md
   - 10_Projects/ で直近7日に更新されたノート（git log --since="7 days ago" --name-only で調べてよい）
   - 00_Inbox/ の件数
2. 30_Resources/me/プロフィール.md の「優先順位」と「いま取り組んでいること」に照らして、次の形で書く：
   ```
   # YYYY-Www 週次レビュー
   ## 進んだこと（事実のみ）
   ## 止まっていること（理由が分かれば一言）
   ## 数字（あれば：note の公開本数・売上・PVなど、ノートに書かれたものだけ）
   ## 来週の優先3つ（優先順位との対応を一言）
   ## AI からの指摘（耳の痛いことを1つ）
   ```
3. 「来週の優先3つ」を _agent/progress.md の「進行中」に反映する。
4. 定期実行で呼ばれた場合は、ユーザーへの質問をせず、判断できない点は「要確認」と書いて終える。

## 注意
- ノートにない数字を作らない。
- 新しいタスクを勝手に始めない（この スキルは振り返りと計画だけ）。
