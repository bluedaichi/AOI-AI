# inbox-triage：Inbox 整理

> [!summary] 何をするスキルか
> スマホから `00_Inbox` に投げ込んだメモを1件ずつ読み、**正しいフォルダへ移してリンクを付ける**。中身は書き換えない。

## 呼び出し方
| 場面 | 言い方の例 |
|---|---|
| メモがたまった | 「Inbox整理して」 |
| 片付けたい | 「メモを片付けて」 |
| 名前で呼ぶ | `/inbox-triage` |

- Inbox が10件以上たまると、AI のほうから提案します（vault-lint の点検で分かります）。

## 使うとどうなるか
1. AI がメモを1件ずつ読み、移動先を決めます
2. 「ファイル名 → 移動先／理由」の一覧が届きます → 「OK」と返す
3. メモが移動し、frontmatter（作成日・タグ）が付きます
4. 関連する既存ノートがあれば、末尾に「関連：」とリンクが付きます
5. 最後に点検（vault-lint）をして、リンク切れがないことを確かめます

## 移動先の決まり
| メモの中身 | 移動先 |
|---|---|
| 期限のある取り組み | 10_Projects/ |
| 続いていく領域 | 20_Areas/ |
| 参考資料・手順 | 30_Resources/ |
| その日の出来事 | 40_Daily/ に追記 |
| 判断できない | Inbox に残す（要確認） |

> [!warning] 確認してから動くこと
> 新しいプロジェクトフォルダを作るときは、名前をあなたに確かめます。

## 変わる前と後（例）

> [!example]- 前：00_Inbox にメモがばらばら
> ```
> 00_Inbox/エアコン掃除の相場.md
> 00_Inbox/note ネタ 現場の動画マニュアル.md
> ```

> [!example]- 後：それぞれの場所へ
> ```
> 30_Resources/エアコン掃除の相場.md
> 10_Projects/note-shueki/note ネタ 現場の動画マニュアル.md
> ```
