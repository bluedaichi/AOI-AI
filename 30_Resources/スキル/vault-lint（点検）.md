# vault-lint：点検

> [!summary] 何をするスキルか
> Vault 全体を点検し、**リンク切れ・frontmatter の抜け・Inbox のたまり具合**を報告する。点検だけで、ファイルは直さない。

## 呼び出し方
| 場面 | 言い方の例 |
|---|---|
| 点検したい | 「点検して」 |
| 名前で呼ぶ | `/vault-lint` |

- Inbox 整理などの作業の最後に、AI が自分で実行します。

## 点検すること
| 項目 | 見るところ |
|---|---|
| リンク切れ | ノート間リンクの先があるか |
| frontmatter | 先頭に作成日があるか |
| Inbox | 件数（10件以上で整理を提案） |
| 引き継ぎ | progress.md が7日以上前か |

- 00_Inbox と _agent は frontmatter の点検から外します。

## 使うとどうなるか
1. AI がまとめて調べ、結果だけが届きます
2. 直したいものがあれば「直して」と返す → 了承を得てから直します

## 変わる前と後（例）

> [!example]- 前：リンク切れに気づかないまま

> [!example]- 後：報告が届く
> ```
> リンク切れ：1件（移住検討 → 小田原の家賃相場）
> frontmatterなし：0件
> Inbox：3件
> ```
