# スキル一覧

> [!summary] 使い方は1つだけ
> 下の「言い方」をそのまま話しかければ、AI が該当するスキルを読んで動きます。
> 名前で呼ぶときは `/スキル名`（例：`/weekly-review`）。スマホからは Remote Control か Dispatch で同じように頼めます。

## 早見表
| やりたいこと | 言い方 | スキル |
|---|---|---|
| メモを片付ける | 「Inbox整理して」 | inbox-triage |
| 調べる | 「〇〇を調べて」 | research |
| 選ぶ | 「AとBどっちがいい？」 | compare |
| 見やすくする | 「〇〇.md を見やすくして」 | md-beautify |
| 記事を書く | 「このメモを note にしたい」 | note-draft |
| ネタを出す | 「ネタ出しして」 | note-ideas |
| 文体を覚えさせる | 「文体を学習して」 | style-learn |
| 第三者チェック | 「レビューして」 | review |
| 振り返る | 「週次レビュー」 | weekly-review |
| 点検する | 「点検して」 | vault-lint |
| 終わる | 「今日はここまで」 | handoff |

## 整理する

### inbox-triage（Inbox 整理）
- **言い方**：「Inbox整理して」「メモを片付けて」
- **使うとどうなるか**：00_Inbox のメモを1件ずつ読み、「ファイル名 → 移動先／理由」の一覧が届く → OK すると移動し、関連ノートへリンクを付ける
- **自動で動くとき**：Inbox が10件以上たまったとき
- 中身は書き換えない（整形と frontmatter の追加だけ）

### md-beautify（ノートを見やすく整える）
- **言い方**：「〇〇.md を見やすくして」「スマホで読みやすく整形して」
- **使うとどうなるか**：結論と次にやることが先頭に来て、表は3列まで、出典は末尾にまとまる。中身は変わらない
- **自動で動くとき**：AI が新しいノートを書くとき（最初からこの書式）
- 詳しく：[[md-beautify（ノートを見やすく整える）]]

### vault-lint（点検）
- **言い方**：「点検して」
- **使うとどうなるか**：リンク切れ、frontmatter の抜け、Inbox のたまり具合の報告が届く

## 調べる・決める

### research（調べもの）
- **言い方**：「〇〇について調べて」「比較材料を集めて」
- **使うとどうなるか**：`30_Resources/research/日付-テーマ.md` に、出典つきのノートができる。最後に「自分の場合の当てはめ」がつく

### compare（比較）
- **言い方**：「AとBどっちがいい？」「決めきれない」
- **使うとどうなるか**：あなたの優先順位（収入 → 筋トレ → 登山 → 家族 → 子ども）で比べた表と、おすすめ1つが届く

### review（第三者チェック）
- **言い方**：「〇〇をレビューして」
- **使うとどうなるか**：書いた本人とは別の AI（Codex）が評価し、`_agent/Reports/` に指摘が届く。note 記事、公開する文章、お金が絡む資料は、書き終えたら自動でこの流れになる

## note・発信

### note-draft（記事の下書き）
- **言い方**：「このメモを note の記事にしたい」「下書きにして」
- **使うとどうなるか**：企画 → 構成 → 下書きの順に進み、`10_Projects/note-shueki/drafts/` に下書きができる。文体は [[文体ガイド]] に従う

### note-ideas（ネタ出し・実績）
- **言い方**：「ネタ出しして」「記事の実績を記録して」「note どうすれば伸びる？」
- **使うとどうなるか**：日々のメモからネタの候補が届く。実績を記録すると、次の打ち手が出る

### style-learn（文体の学習）
- **言い方**：「文体を学習して」「私っぽく書けるようにして」
- **使うとどうなるか**：あなたが書いた文章から特徴を抜き出し、[[文体ガイド]] が更新される
- **自動で動くとき**：あなたが下書きを大きく直したとき

## 振り返る・引き継ぐ

### weekly-review（週次レビュー）
- **言い方**：「週次レビュー」「今週の振り返り」
- **使うとどうなるか**：`40_Daily/2026-W41-review.md` のようなノートができる。中身は進んだこと、止まっていること、数字、来週の優先3つ、耳の痛い指摘1つ

### handoff（引き継ぎ）
- **言い方**：「今日はここまで」「引き継ぎ」
- **使うとどうなるか**：`_agent/progress.md` が更新され、次のセッションでは続きから始まる

> [!tip] 新しいスキルを作ったら
> AI がこのフォルダ（30_Resources/スキル/）に説明ノートを作り、この一覧に1行足します（AGENTS.md のルール）。
